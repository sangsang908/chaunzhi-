# 智学AI - 智慧教育平台

> 融合 AI 技术与 Web 前端框架的智慧教育网站应用

## 项目简介

**智学AI** 是一个面向学生的 AI 驱动智慧学习平台，围绕"智慧教育"主题设计，通过将人工智能技术与现代 Web 前端技术深度融合，打造个性化、智能化的在线学习体验。

## 核心功能

| 功能模块 | 描述 |
|---------|------|
| 🤖 AI 智能助教 | 7×24h 在线答疑，支持多学科问题解析，拟人化对话交互 |
| 📚 个性化学习路径 | 基于 AI 分析用户学习数据，智能推荐课程与学习顺序 |
| 🕸️ 知识图谱 | 可视化展示知识点关联，直观呈现掌握程度与薄弱点 |
| 📊 学习数据报告 | 多维度数据可视化（柱状图、折线图、雷达图），洞察学习效果 |

## 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite
- **样式方案**: Tailwind CSS v4
- **路由管理**: React Router v6
- **数据可视化**: Recharts
- **图标库**: Lucide React

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 设计理念

本项目以"AI助力教育公平与效率"为核心理念，通过以下方式实现智慧教育：

1. **个性化** - 根据学习数据动态调整推荐内容
2. **可视化** - 知识图谱让学习结构一目了然
3. **数据驱动** - 量化学习过程，反馈真实效果
4. **智能交互** - AI 助教随时解答，降低学习门槛
